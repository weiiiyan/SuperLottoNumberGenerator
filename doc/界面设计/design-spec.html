组件与配色规范

两套主题共用一套布局骨架，只替换视觉令牌。本页是给开发照着实现的唯一参照：尺寸、间距、状态、映射到 classic/style.qss 与 LottoUi/*.qml 的写法。

01 · 共用布局骨架

之前两套界面的问题不是配色，而是结构不同：经典版是 QWidget 竖排 + 角落菜单，新拟物版是 QML 的 ColumnLayout + 底部胶囊，标题位置、时间条位置、按钮顺序都不一样。使用者切换主题时等于换了一个应用。

现在统一为下面这一张骨架。两套主题行高、间距、控件顺序、点击区域全部一致，只允许改：背景、号码球外观、按钮质感、分隔线样式。

骨架规则

  • 顺序固定：顶栏 → 时间条 → 号码区 → 骑缝线 → 票号 → 操作区。不允许在中间插入风格专属控件。
  • 号码区吸收余高：5 行等分剩余空间，单行最大 86px；窗口变矮时先压缩行高，再压缩间距，不出现滚动条。
  • 操作区贴底：占 72px 固定高度，左锁定、右生成，生成按钮更宽（比例 1 : 1.32）。
  • 风格入口唯一：右上角一个 32px 按钮，弹出底部抽屉。删除原先经典版的 QToolButton 菜单与新拟物版的底部胶囊两套入口。

02 · 经典主题 · 票券

原来经典版的问题是"没设计感"：纯色红块按钮、圆角矩形号码、没有主次。新方向把它做成一张彩票票根——纸面、骑缝线、票号、锁定印章。号码球是绝对主角，其余元素全部退成细线。

03 · 新拟物主题（保持风格，只换骨架）

实现要点

  • 删除 NeumorphicView.qml 底部的 NeumoPill 胶囊行，风格入口收到右上角按钮。
  • 球径从 44 改为 36，NeumoTicketRow 的 ballSize 直接绑定骨架常量，不再按宽度反算（反算会导致与经典版行高不一致）。
  • RectangularShadow 的 blur 在 36px 球上要到 8–9，否则阴影会糊在一起；shadowOffset 同步取 3。
  • 分隔线用 1px 线性渐变（中间实、两端透明），替代硬线，符合柔面语言。

动效

  • 换号时号码球逐个 scale .72 → 1，每球延迟 16ms，总时长 340ms，缓动 cubic-bezier(.2,.85,.3,1.25)。
  • 锁定印章从 rotate(-7deg) 微放大淡入，220ms。
  • 风格切换：旧界面快照淡出 240ms（沿用现有 LottoStyleSwitchOverlay，不需要改）。
  • 系统开启「减少动态效果」时全部关闭。

05 · 改动清单

经典主题（QWidget）

  • lottoclassicview.cpp：buildLayout() 按新骨架重排——顶栏、时间条、票号行、操作区。
  • 时间标签从两个拼接 Label（#timeLabel / #timeValueLabel）改为一行「标签 + 值」，去掉红色胶囊底。
  • 号码球固定 36px，删除按屏幕宽度反算球径的逻辑（updateLabelSizes 里的 LABEL_ROW_WIDTH_FRACTION 分支）。
  • 新增票号行与骑缝线（可用 QFrame + paintEvent 画半圆缺口）。
  • 锁定/生成按钮顺序调整为「左锁定、右生成」，宽度比 1 : 1.32。
  • style.qss 按本页令牌重写，删除 #btnStyleSwitch 菜单相关样式。

新拟物主题（QML）

  • NeumorphicView.qml：根 ColumnLayout 的 spacing 从 14 改为与经典版一致的 13 / 14 / 10 分段。
  • 时间行 NeumoValueRow 改为整行两端对齐（标签左、值右）。
  • NeumoTicketRow.qml：ballSize 固定 36，行高 ballSize + 2 × 3。
  • 删除 NeumoPill.qml 的使用；保留文件或一并删除均可。
  • 新增票号行与骑缝线（Canvas 画半圆，或两个圆形 Rectangle 叠在边界上）。
  • NeumoTheme.qml 令牌值不变，仅补 ballSize: 32 常量。

共享层（建议）

把骨架常量收到一个共享头文件，两套视图都引用，避免下次再漂移：

// src/ui/lottolayoutmetrics.h
namespace LottoLayout {
inline constexpr int CanvasWidth  = 390;
inline constexpr int PadX         = 22;
inline constexpr int BallSize     = 36;
inline constexpr int BallGap      = 5;
inline constexpr int RowIndex     = 18;
inline constexpr int ActionHeight = 52;
inline constexpr int PerfHeight   = 26;
}

QML 侧通过 qmlRegisterUncreatableType 或直接在 NeumoTheme.qml 里镜像同一组数值；两处数值若不一致，以本页为准。
