这次统一了什么

01

位置一致

时间信息从"经典版居中红胶囊 / 新拟物版左侧纯文本"统一为一行两端对齐；主按钮从"左生成右锁定"统一为"左锁定右生成"，与大多数表单的"次要操作在左"一致。

02

尺寸一致

号码球统一 40px（390 宽下的上限；原经典版按屏宽反算、新拟物版 44px），行高 76、球距 4、行距 0，全部来自同一组常量；余高交给两行票根区，窗口缩放时两版以同样方式压缩。

03

入口一致

风格切换从两个不同入口（角落 QToolButton 菜单 / 底部胶囊行 + 图标按钮）收敛为右上角一个按钮 + 底部抽屉。

04

反馈一致

锁定状态在两版里都以"生成按钮禁用 + 锁定按钮反色 + 票根印章"三重反馈呈现，不再依赖各主题自己的视觉暗示。

05

节奏一致

号码带收紧到 36px 球缘间距，省出的高度转给票根与操作区；两版在 390×844 下共用同一组骨架高度（66 / 60 / 380 / 105 / 81）。
